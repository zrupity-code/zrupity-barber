# Zrupity Barber · site vitrine de démonstration

> **Site fictif.** Zrupity Barber n'est pas un vrai salon : l'équipe, l'adresse, le téléphone, les tarifs et la note sont imaginaires. Projet réalisé par [Zrupity Développement](https://zrupity-developpement.vercel.app/) pour montrer son savoir-faire.

**Voir le site en ligne : https://zrupity-code.github.io/zrupity-barber/**

React + TypeScript + Vite + Tailwind CSS v4 + Framer Motion + Leaflet.

## Points forts

- Accueil avec **prisme 3D** : une coupe vue sous 4 angles, qui tourne à l'infini à la molette dans la zone délimitée, au glisser (souris ou doigt), et lentement au repos
- Statut « ouvert / fermé » et **prochain créneau libre** calculés en direct à partir des horaires
- **Prise de rendez-vous** en 4 étapes : prestation, barbier, jour et créneau, coordonnées
- Services avec aperçu photo au survol, galerie de styles (dégradé haut, dégradé bas, taper, coupe rase…)

## Démarrer

```bash
npm install
npm run dev
```

Le site est disponible sur http://localhost:5173.

## Scripts

- `npm run dev` : serveur de développement
- `npm run build` : build de production (`dist/`)
- `npm run preview` : prévisualiser le build de production
- `npm run lint` : vérification du code avec Oxlint
